Theme: Auto

Adaptive Context

This layout implicitly inherits the global website theme state. When the system is dark, the particles glow brightly. When you invert the global page theme, it hot-swaps to its defined Light-Mode color arrays seamlessly.

Opposite State

Designed implicitly to oppose the container context. If your website is dark, this visual element forces its `light-mode` styling parameters. This creates tremendous visual tension and contrast for highlight panels!

Strict Dark Lock

Regardless of what the user does with the website theme toggle above, this section forces an explicit Dark-mode processing state—always rendering high-definition additive bloom gradients securely.

This layout maintains an unyielding Light Mode implementation. The engine automatically swaps to multiplicative blending logic, dropping bloom passes entirely, to guarantee visual clarity on bright backgrounds.
